# Privacy Policy

**Effective date:** September 8, 2026

Focus Input does not collect, transmit, sell, or share personal data.

The app observes foreground application changes locally so it can apply user-created input-source rules. It does not record an application-activity history or send activity anywhere. Configured application bundle identifiers, display-name snapshots, input-source identifiers, and app settings are stored only on the user's Mac using `UserDefaults`.

Focus Input contains no networking, advertising, analytics, telemetry, crash-reporting service, account system, cloud synchronization, or third-party runtime code. It does not use Accessibility, AppleScript, simulated keyboard shortcuts, private APIs, or a helper process.

Questions about this policy can be submitted through the repository's [GitHub Issues](https://github.com/alexeyvax/code-input-en/issues).
